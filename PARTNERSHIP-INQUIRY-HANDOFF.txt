PERSISTENCE / CONTRACT
POST /api/partnership-inquiry validates server-side, bounds JSON bodies to 32 KiB even
without Content-Length, and enforces field limits. It uses the existing forward helper
and /api/v1/public/enquiries backend, kind=partner. All new details are assembled in the
existing message field, under its 3,000-character limit, so current Admin retains them.
Receipt is returned only for backend HTTP 200 plus a nonblank saved reference.
Backend 429 and failures are surfaced without exposing private upstream error messages.
Optional Resend notification reuses existing configuration and plaintext email; it follows
persistence, and a notification exception does not undo an already-saved enquiry.
No backend schema migration or new backend deployment is required for this representation.
